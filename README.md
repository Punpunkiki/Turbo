# TURBO TRUST — ต้นแบบแอปพลิเคชัน

แอปพลิเคชันต้นแบบ (mobile-first) สำหรับแบรนด์นายหน้าประกันภัยดิจิทัล **TURBO TRUST** ในเครือเงินเทอร์โบ
สร้างขึ้นเพื่อประกอบการนำเสนอในการแข่งขัน business case ข้อมูลทั้งหมดเป็น mock data ไม่มี backend

---

## วิธีรัน

```bash
npm install && npm run dev
```

เปิดที่ **http://localhost:5180**

### เปิดบนมือถือจริง

เซิร์ฟเวอร์เปิด `host: true` ไว้แล้ว ให้ต่อมือถือเข้า Wi-Fi วงเดียวกับคอมพิวเตอร์ แล้วเปิด URL ที่ขึ้นในบรรทัด
`Network:` ตอนสั่ง `npm run dev` (เช่น `http://192.168.1.34:5180`)

### สร้างไฟล์สำหรับนำไปเปิดที่อื่น

```bash
npm run build
```

ได้ผลลัพธ์ในโฟลเดอร์ `dist/` เปิดดูแบบ static ได้ด้วย `npm run preview`
ฟอนต์ถูกฝังมาในโปรเจกต์แล้ว ดังนั้นแอปทำงานได้แม้ตอน demo อินเทอร์เน็ตล่ม

## User flow ที่กดผ่านได้จริง

```
เปิดแอป  →  เลือกผลิตภัณฑ์  →  เทียบราคา  →  ซื้อ 3 ขั้นตอน  →  กรมธรรม์ e-Policy  →  หน้าแรก
 Splash      Products         Quote         Buy               Success            Home
                                                                                  │
                                                       ┌──────────────────────────┼──────────────┐
                                                   กรมธรรม์          แจ้งเคลม           สาขาใกล้ฉัน
                                                    Policy            Claim              Branches
```

ทุกหน้ามีทางไปต่อและทางย้อนกลับเสมอ ไม่มีทางตัน — ผลิตภัณฑ์ทั้งสามกลุ่ม (ไรเดอร์ / ร้านค้า / รถยนต์)
เดินได้ครบ flow เหมือนกันหมด

**บนเดสก์ท็อป** จะเห็นเป็นเฟรมมือถือกลางจอ พร้อมแผงด้านซ้ายสำหรับผู้นำเสนอที่กดข้ามไปหน้าไหนก็ได้ระหว่าง
demo สด **บนมือถือ** เฟรมจะหายไป กลายเป็นแอปเต็มจอ

## จุดที่ตั้งใจให้เป็นไฮไลต์ตอนพิตช์

1. **สวิตช์เปิด-ปิดความคุ้มครอง** ที่หน้าแรก — จับต้องได้ว่า Pay-As-You-Ride คืออะไร
   มีนาฬิกานับเวลาที่คุ้มครองจริงเดินอยู่ และแถบแสงวิ่งบนการ์ดตอนเปิดใช้งาน
2. **ตัวเลื่อน "คุณใช้งานบ่อยแค่ไหน"** ที่หน้าเทียบราคา — เลื่อนแล้วเบี้ยขยับทันที
   และแอป**บอกตามจริงทั้งสองทาง**: เลื่อนไปที่ 3 วัน/สัปดาห์ จะบอกว่าประหยัดกว่าประกันรายปี 40%
   แต่เลื่อนไปที่ 7 วัน/สัปดาห์ จะบอกตรง ๆ ว่าประกันรายปีคุ้มกว่า พร้อมบอกจุดคุ้มทุน
   จุดนี้ตอบคำถามกรรมการเรื่องความน่าเชื่อถือของโมเดลได้ดีกว่าตัวเลขที่ดูดีด้านเดียว
3. **ซื้อจบใน 3 ขั้นตอน** ไม่มีการอัปโหลดเอกสาร และได้กรมธรรม์อิเล็กทรอนิกส์ทันทีที่ยืนยัน
4. **สาขาใกล้ฉัน** — สื่อว่า Community Layer ยังอยู่ ซื้อออนไลน์แต่เดินเข้าสาขาเงินเทอร์โบได้

ที่หน้าแรก ถ้าเลือกจ่ายแบบ "รายเที่ยว" จะมีปุ่ม **จำลองรับงาน** ให้กดโชว์ว่าเบี้ยขยับตามจำนวนเที่ยวจริง

## ข้อจำกัดของต้นแบบ

- ตัวเลขเบี้ย ความคุ้มครอง สาขา และระยะทาง เป็นข้อมูลจำลองทั้งหมด
- QR code เป็นภาพจำลอง สแกนไม่ได้
- สถานะเก็บในหน่วยความจำ รีเฟรชหน้าแล้วเริ่มใหม่ (ตั้งใจ เพื่อให้ demo ซ้ำได้ง่าย)
